## 失败链路

初始 Planner 的行为目标覆盖 skipped 状态在读取、汇总、事件和存储恢复中的一致性，但只对已观察到明确错误的汇总实现提出 EDIT。结果转换、执行上下文及领域状态保持 INSPECT，不能据此声称原 Plan 已给出完整可执行修复范围。

Coding 读取汇总实现、精确修改并主动提交候选。公开 build、typecheck、lint 通过，test 未通过。公开失败回到同一 Session 后，Agent 查询关系图、读取结果转换实现并提出 `SCOPE_CONFLICT`。第一次交接缺少所提议持久化目标的当前实现证据；现有有界补正允许读取 `src/persistence/run-serializer.ts`，随后再次提交范围冲突。候选通过核实，但未取得新增写权限。
