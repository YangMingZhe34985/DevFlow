## 确定性修复与免费验收

此前 E02 SDK 解析后的 `queryRelations.paths` 是混入 XML 标记的字符串，`symbols` 没有成为独立字段。Worker 自定义查询只返回简化 `VALIDATION_ERROR`，没有通用的参数错误分类与纠正提示，因此未进入已有恢复分支，在第二轮无进展处停止。历史没有保存原始 Provider 响应，无法进一步确定非法结构由模型原文还是 SDK 解析产生。

本批保留严格 Schema，返回具体字段、预期/实际类型及正确参数结构，允许模型显式纠正。参数恢复与现有编辑格式/LENGTH 恢复共享一次信用；无效调用仍计为无进展，只在尚有纠正信用时暂缓停滞终止。合法但无新证据的纠正不能重置计数，权限和探索拒绝不授予纠正机会。

纠正决策前持久化 `pending=true/used=true`，整个决策提交后才解除 pending。中断恢复没有已提交结果时明确阻断，避免重启重新开放工具；消费、期限和信用不重置。

原失败请求经实际 Worker、SDK 模拟 HTTP 和 Docker 回放：非法查询 → 字段反馈 → 显式数组纠正 → 当前 SHA 关联实现证据 → 合法交接。三次模拟 HTTP、零付费；非法查询源码读取 0，合法查询实际读取 1。回放保留旧计数，历史期限过期后使用明确标注的合成期限，不把它当作历史费用或真实修复验收。

完整工程验收 **997 PASS、31 SKIP**，lint、typecheck、格式及公开文件检查通过。新 Runtime 恢复回归 **16/16**，工具包 **29/29**，最终源码原请求 Docker 回放通过。
