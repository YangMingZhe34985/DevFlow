# 新 Review 实现与九题真实验收（2026-10-06）

三批实现及免费验收已完成。九题均从 Localization 开始重新运行一次：Planner 接收与进入 Execute 为 **9/9**，最终公开 Test 为 **9/9**，独立补丁验收为 **8/9**，严格端到端通过为 **6/9**。独立补丁验收与 Review 批准分别报告；通过测试不代表所有公开 API 边界均正确。

## 已实现的行为

1. Review 保持无直接工具调用。宿主验证源码引用、当前 SHA、任务关系和基准比较；只有已确认、可行动的 Issue 未修复或补丁回归进入 Repair。无关既有缺陷保留为 `DEFERRED`，旧 finding 不因遗漏而关闭。
2. 源码补证与公开复现共用两轮反馈。源码配额、复现请求版本、纠正额度、finding 历史和消费记录均持久化。`assertBehavior` 将行为失败与脚本、依赖、入口、超时等错误分开；脚本报错或非零退出码本身不证明缺陷。
3. `LENGTH` 答案即使能解析为 JSON，也不作为裁决。正常审查使用 high 思考；语义恢复使用同一模型的 low 思考、紧凑完整证据和相同输出上限。完整非空答案的格式转换仍关闭思考。每次裁决最多一次恢复，全流程共享两次额度。
4. 请求前检查步骤、输入、配置输出、时间和费用，预留恢复及后续裁决。预算不足会记录缺口，停止发出请求；保护测试和批准修改范围继续由宿主管理。

公开行为和配置见 [工作流](v2-workflow.md)与[阶段模型](stage-models.md)。Planner 契约、Localization 架构和独立评分规则没有在本轮重构。

## 三个失败案例的归因

**#5296：Review 未完成，主要是时间预留不足。** Execute 初次修改引发公开测试错误，Test Repair 已修复，随后公开 Test 和保存候选的独立验收均通过。第一次 high 审查截断，low 恢复要求补查 v3 record 路径及 `$ZodPipe` 定义。宿主补证成功，但下一次 high 请求发出时只剩约 174 秒，最终撞到整个工作流的 15 分钟限制。它没有给出最终拒绝结论，不能记作 Review 误拒。当前时间预检没有为长思考裁决预留足够实际延迟，这是后续应优先修复的工程问题。

**#5825：定位/计划目标错误，Review 拒绝正确。** 公开 Issue 给出法语 `number` 应显示为 `nombre` 的实例，批准计划却只允许修改丹麦语 `da.ts`。实际补丁没有修复法语 `fr.ts`，独立 Issue 验收也失败。Review 补证后指出了同一个真实问题。Repair 尝试修改法语文件时被范围保护拒绝，随后未能获得重新规划的范围。公开 Test 通过不能覆盖该失败。后续需要保证修改目标覆盖原始复现，并为 `SCOPE_CONFLICT` 提供显式重新规划出口。

该题还暴露了复现请求接口问题：模型为首次请求自行填写了宿主尚未分配的 probe ID，被记录为 `UNKNOWN_PROBE_ID`，没有执行。该错误不能用作缺陷证据。补证后的源码推导与独立验收仍足以确认法语问题。下一轮需要改善首次 ID 与断言参数类型的模型说明，并保留 Repair 前未关闭 finding 的有效源码证据，避免重复补读。

**#5826：真实额外行为与任务关系未完成裁决，不能简单归为误拒。** 候选修复了公开 Map 复现，独立验收通过。Review 指出浅复制仍会共享嵌套数组，但连续三次把 Planner 扩展后的摘要填写为原始 Issue 的 `taskQuote`。宿主没有在原始任务中找到该引用，因此保留 `SCOPE_UNDETERMINED` / `NEEDS_EVIDENCE`，没有把它转成已确认缺陷交给 Repair。两轮源码补读不能纠正错误的任务依据，最终停止。

另行进行零模型费用、隔离只读的公开 API 复现，确认保存候选的 SHA 与审查引用一致：原始 Map 实例在基准失败、候选通过；Review 提出的 `[[]]` 嵌套共享在基准和候选都失败。这证明嵌套共享是实际既有行为，但不自动证明它必须阻断本次任务，也不自动将其归为无关缺陷。后续应明确区分原始 Issue 要求和 Plan 的解释；任务范围补证应返回具体引用错误并要求重新裁决，而非继续读取相同代码。

**已知历史错误论据的状态：** 新 #5777 的最终 Review 明确认可已有 `extractDefs` 的 cycle 处理，不再使用“cycle 未处理”或“必然空 schema”的论据；补丁及严格流程通过。新 #5792 通过，未被额外正指数边界阻断；但真实该题没有生成 `DEFERRED` finding，不能把免费脚本化回放的结果冒充真实模型的范围判断。
