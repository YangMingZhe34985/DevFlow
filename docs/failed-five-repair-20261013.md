## 团队协议与来源引用修复

- 每条实际展示的证据增加确定性的短 `reference`，绑定完整证据 ID 和源码身份。模型可以明确选择该引用；宿主只解析本次已展示映射，之后仍校验当前身份、来源完整性和访问权限。完整 ID 保持兼容；未知、前缀、过期或未展示的短引用不匹配、不猜测。完整原始输出和规范化操作分别持久化，恢复不改变映射身份。
- 严格决策 Schema 错误纳入现有一次 Session 协议纠正，保留具体字段及原输出。未识别字段仍拒绝，宿主不会删除字段后擅自执行。纠正与证据／消息参数错误共用额度，重复错误停止，预算仍在请求前检查。
- 原 E07 冻结动作免费回放通过：带 `dependsOn` 的 SEND 被拒绝，受控模型明确纠正后消息送达，接收者收到反馈，团队可交接规划。保留原累计决策次数；该回放仅证明工程链路。
